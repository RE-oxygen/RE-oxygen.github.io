01 / THE QUESTION

“打扫干净了吗？”
这件小事并不简单。

清洁需要不断确认：空间里有什么、工具放在哪里、哪里还没有完成。对低视力使用者而言，这些判断可能需要他人协助。我们把问题聚焦在日常家务中最具体的一件事——如何让清洁过程更可感知、更可自主？

01 / 找到

环境与工具

开始前，需要知道房间布局、障碍物和清洁工具的位置。

02 / 完成

连续的动作

清洁过程中，双手可能被占用，指令需要跟随当下任务。

03 / 确认

遗漏与进度

结束时，需要一个可以回顾的判断，而非只凭感觉猜测。

02 / HUMAN CONTEXT

先理解生活，
再定义功能。

SCENARIO PERSONA / 情境人物
“我想自己把房间收拾好，
不用每次都等室友帮忙。”

工作坊以搬到首尔独立生活的低视力学生 Kim Ji Eun 为情境人物，推演她在寻找工具、规划路线和确认清洁结果时会遇到的困难。这个人物用于设计推演，并非真实受访者。

01保持自主

把信息交还给使用者，由本人决定下一步。

02解放双手

在清洁动作中，主要反馈通过声音到达。

03适应情境

根据任务切换佩戴位置，保留灵活的使用方式。

03 / THE SYSTEM

一枚核心设备，
接入整个清洁流程。

方案由可佩戴设备与手机应用组成。设备通过摄像头感知眼前环境，以定向声音提供提示；应用负责连接设备、设定日常清洁流程与回看任务。不同部件承担不同的工作，避免把全部操作压在手机屏幕上。

01 / SEE摄像头

辅助识别空间、工具与清洁状态。

02 / SPEAK语音反馈

说明位置、下一步动作与障碍提醒。

03 / CONNECT手机应用

配对设备，设置流程并查看完成情况。

04 / FORM FOLLOWS TASK

同一枚设备，
跟着动作改变位置。

01 / 日常准备

戴在手腕，随时开始。

腕带形式适合进入房间、寻找工具和启动任务；需要双手清洁时，可以把核心模块移到其他配件上。

02 / 持续清洁

挂在胸前，双手留给行动。

在擦洗浴室等任务中，挂绳让设备保持在身前，摄像头视角与作业方向更接近，同时减少手腕上的负担。

03 / 按需固定

夹在衣服上，按情境调整。

夹扣提供另一种固定方式。共用的磁吸连接结构，让设备能够在不同配件之间快速切换。

设计概念 / 共用磁吸接口让核心设备在不同配件之间切换

05 / THE JOURNEY

从开始到结束，
每一步都有回应。

我们把家务拆成准备、执行和确认三个阶段。点击下方阶段，查看设备如何在不同时间提供恰好需要的信息。

BEFORE CLEANING

开始前，先建立一张声音地图。

设备扫描房间，说明空间结构、障碍与清洁工具的位置；用户在应用中选择本次任务和清洁流程。

空间说明工具定位流程设置
DURING CLEANING

行动中，只给下一步需要的提示。

针对捡拾、拖地、浴室清洁等任务，语音逐步提示动作与行进方向；遇到障碍时给出警示，并允许用户切换设备佩戴位置。

分步引导障碍提醒自由切换
AFTER CLEANING

结束后，让完成感有依据。

方案通过图像辅助评估清洁状态，并以语音反馈结果。应用保留清洁记录，为下次整理提供参考。

状态检查语音反馈任务回顾
06 / INTERACTION DESIGN

让界面退后，
让行动向前。

VOICE FIRST, SCREEN WHEN NEEDED

视觉界面依然存在，但在移动与清洁时，主要信息由语音传达。应用把配对、房间扫描、例行任务和结果反馈放在清晰的顺序里。

大触控区域 ／ 单列信息 ／ 语音确认
  1. 01

    连接设备

    完成配对，确认设备已准备好。

  2. 02

    扫描房间

    了解布局、工具与需要注意的位置。

  3. 03

    选择清洁流程

    按照任务逐步行动，并接收障碍提醒。

  4. 04

    完成与回看

    听取反馈，回顾本次清洁。

07 / REFLECTION

辅助设计的重点，
是把选择权留给人。

设计决定

从固定产品到可切换系统

同一枚核心模块连接不同配件，让设备适应清洁动作，而非要求用户始终维持一种姿势。

交互决定

从视觉操作到声音引导

在需要行动的时刻，以短而明确的语音提示位置、步骤和变化，减少反复查看手机。

需要继续验证

走进真实家庭场景

设备视角、声音私密性和清洁状态判断仍需与不同视力状况的使用者一起测试与迭代。
